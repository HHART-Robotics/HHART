# Agentic workflow

Optional instructions for coding agents working on this robot. They aren't
HHART rules and nothing checks them. Delete the folder if you don't need it.

| File | |
| --- | --- |
| [AGENTS.md](AGENTS.md) | What agents can change, what needs a person, how to verify |
| [DESIGN.md](DESIGN.md) | Operator UI design guidelines |
| [BINDING.md](BINDING.md) | Connecting the UI to the contract |
| [FRONTEND.md](FRONTEND.md) | Building the robot's own UI views |

To use them, copy or link `AGENTS.md` to the repo root, or add
`@agentic-workflow/AGENTS.md` to `CLAUDE.md`.
